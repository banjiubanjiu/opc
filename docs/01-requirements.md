# OPC 社区网站需求

## 定位
一人公司社区网站,线下社群,科技向善,面向国内,对外发布。

**差异化**:竞品(opc.community)偏"搞钱/风口"路线;我们主打"清醒、真实、向善",用真实实践者声音做内容,不贩卖焦虑,视觉走冷静克制简约风。

## MVP
1. 页面:首页、关于、活动列表+详情、报名
2. 报名:线上免费登记(内嵌表单),现场收 49 元茶水费
3. 活动字段:时间、地点、主题、嘉宾
4. 内容:活动/文案存数据文件,改文件即更新,不动代码

## 非功能
- 移动端优先
- 国外部署+CDN,免备案,国内可访问
- 单人维护,低成本
- 视觉美观

## 技术(MVP)
- Astro + Tailwind
- 部署:Cloudflare Pages / Vercel
- 表单:内嵌 + 表单后端
- 支付:MVP 不做线上支付,现场扫码

## 验收
- 4 个页面可访问
- 报名可提交,数据可导出
- 新增活动只改数据文件
- 国内访问流畅

## 后期(不做入 MVP)
- 短动态社区、微信在线支付、注册登录、活动回顾、会员
